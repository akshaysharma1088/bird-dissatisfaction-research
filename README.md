# BIRD — Behavior-Informed Recognition of Dissatisfaction

Private research workspace for studying customer dissatisfaction across social-media and help-agent conversations.

## Research integrity

- Keep raw source corpora, customer transcripts, API keys, and annotator/source mappings **out of Git**.
- Publicly available research-elicited dialogues are **not** production Salesforce or Amazon customer records.
- **Polarity**, expressed **dissatisfaction**, and actual **customer satisfaction** are different constructs.
- Human gold labels, multilingual robustness results, and GPT/Haiku comparative results are **not yet available**.

## Next milestone

Build the 30-complete-dialogue calibration pilot (15 ASAPP ABCD + 15 Amazon Research MultiDoGO software conversations), review privacy manually, obtain independent human annotations, and only then report performance.

Workflows and collection tools will be introduced through a reviewed pull request.
